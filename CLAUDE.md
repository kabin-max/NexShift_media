>
> * Keep the exact same theme as the homepage.

> * Maintain identical typography, spacing, and border radius.
> * Include Framer Motion animations.
> * Add smooth scrolling reveal effects.
> * Use glassmorphism where appropriate.
> * Make every section responsive for mobile, tablet, and desktop.
> * Use Lucide React icons.
> * Optimize for SEO with proper semantic HTML.
> * Add subtle hover effects and transitions.
> * Ensure accessibility (ARIA labels, keyboard navigation, sufficient contrast).
> * Build the page using reusable React components (or the existing framework) so it integrates seamlessly with the current website.
